# Photo Assets Folder

Drop your photos here!

For example:
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`

Then in `config.js`, simply update the `image` field in `CONFIG.memories`:
```javascript
{
  image: "assets/images/photo1.jpg",
  caption: "Beach trip",
  date: "Summer 2024",
  message: "Your special message here..."
}
```
Autocommit will automatically push your new pictures to GitHub!
